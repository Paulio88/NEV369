# NEV369 Layer-1 Blockchain

**High-performance Rust Layer-1** with post-quantum security, real P2P networking, and a fixed supply of **369,369,369 NEV**.

Built solo. Dedicated to **Nevaeh** — Heir of the Chain.

---

## Features

- **Post-Quantum Signatures**: Dilithium
- **Proof-of-Work**: SHA-512
- **Networking**: Real **libp2p** (Gossipsub + mDNS + Identify + Ping + QUIC/TCP)
- **Database**: Sled (embedded)
- **Fixed Supply**: 369,369,369 NEV
- **Premine**:
  - 10,000,000 → Architect
  - 36,900,000 → Nevaeh Vault
- Fully open-source
- Solo-developer project (no VC, no team)
